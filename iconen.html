Toegankelijk gebruiken

Combineer een icoon altijd met een tekstlabel, zodat de betekenis ook zonder icoon duidelijk is.

Decoratief (naast tekst die hetzelfde zegt): gebruik een lege alt-tekst, alt="". Schermlezers slaan het icoon dan over.

Informatief (zonder tekst erbij): geef een beschrijvende alt-tekst, bijvoorbeeld alt="Afval".

Direct uit GitHub

Ontwikkelaars kunnen iconen rechtstreeks uit de repository laden, waardoor de set altijd actueel blijft op websites.
